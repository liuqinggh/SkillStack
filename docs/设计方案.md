**Skill 统一管理工具 - 完整设计方案**
**（含项目级 Skill 管理）**
**版本**：v1.0（2026年4月）
**适用场景**：个人开发者 & 小团队，使用 Claude Code / Cursor / OpenCode 等多 Agent 工具，需要统一管理全局 + 项目级 Skill 的场景

### 1. 设计目标

- **核心痛点解决**：实现 Skill 的**集中式单源真相**管理，彻底解决“到处都是 Skill、手动 copy、漂移、版本混乱”的问题。
- **分级管理**：支持 **全局（User-level） + 项目级（Project-level）** 两层管理，完美匹配 Claude Code 等工具的三层优先级（Project > User > Bundled）。
- **核心能力**：CRUD（增删改查） + 多平台/多项目同步 + 版本管理 + 可视化概览。
- **用户体验目标**：一键同步、零漂移、操作比手动管理快 10 倍，支持 GUI 和 CLI 双模式。

### 2. 系统架构（高层次设计）

采用 **“中央仓库 + 项目注册表 + 适配器投影”** 架构：

- **中央仓库**（单源真相）：存放所有 Skill 的权威版本（Git 友好）。
- **项目注册表**：记录用户所有受管项目及其 Skill 状态。
- **工具适配器层**：负责把中央仓库的 Skill “投影”到各个目标工具的目录（Claude、Cursor 等）。
- **同步引擎**：负责全局、项目级的增量同步（优先 symlink，fallback copy）。

架构优势：

- 所有变更只在中央仓库操作，项目层仅为“覆盖层”。
- 支持项目级 override（项目 Skill 自动优先于全局）。
- 易扩展到更多工具或企业级云同步。

### 3. 核心概念与数据模型

- **Skill 定义**：采用标准格式（SKILL.md + YAML frontmatter），包含 name、version、description、triggers、capabilities 等元数据。
- **仓库结构**（逻辑描述）：
  - 中央仓库目录：存放所有 Skill 文件夹 + manifest（用户意图清单） + lock（实际状态快照）。
- **项目注册表**：记录每个项目的路径、名称、工具类型、Skill 使用状态（哪些 Skill 被安装/override）。
- **同步状态**：每个 Skill 在每个项目中的状态（已同步、已 override、漂移、过期）。

### 4. 功能模块设计（重点：项目级 Skill 管理）

#### 4.1 项目注册与扫描

- 支持用户手动添加/移除项目路径（支持多个项目根目录）。
- 自动扫描项目目录下的 `.claude/skills/`（或其他工具对应路径）。
- 项目列表视图：显示项目名称、路径、Skill 数量、最后同步时间、Git 状态。
- 支持批量导入（扫描指定文件夹下的所有子项目）。

#### 4.2 统一 Skill 视图与管理

- **全局视图**：展示中央仓库所有 Skill（可按名称、频率、版本排序）。
- **项目视图**（核心功能）：
  - 选择工具（如 Claude）→ 显示“所有项目”列表或具体项目。
  - 进入某个项目后，显示该项目当前拥有的所有 Skill（来自项目本地目录）。
  - 同时显示可从中央仓库“安装/同步”的 Skill 列表。
  - 突出 override 关系：同名 Skill 高亮显示“项目覆盖全局”。
- **CRUD 操作（全局 + 项目级）**：
  - **创建**：在中央仓库新建 Skill → 可选择立即同步到指定项目（或全部项目）。
  - **查看**：Skill 详情页显示在哪些项目中使用、版本历史、override 情况。
  - **编辑**：修改中央仓库版本 → 可选择性推送更新到项目。
  - **删除**：
    - 全局删除：从中央仓库移除，同时可选清理所有项目中的链接。
    - 项目级删除：仅移除该项目的 Skill（不影响中央仓库和其他项目）。
  - **同步/部署**：支持“同步到单个项目”“同步到所有项目”“仅同步变更部分”等粒度。
- **批量操作**：选中多个 Skill 或多个项目，一键批量安装/更新/禁用。

#### 4.3 版本管理

- 中央仓库采用语义化版本（semantic versioning）。
- 项目级可独立锁定版本（项目A 用 v1.2.3，项目B 用 latest）。
- 支持 diff 对比（中央仓库 vs 项目本地）。
- 回滚功能：指定项目 + Skill + 历史版本一键回滚。
- 自动更新提示：检测到新版本时，列出受影响的项目并提供一键升级。
- 变更日志：记录每次同步的操作历史。

#### 4.4 健康检查与冲突解决

- “医生”模式：扫描全局 + 所有项目，检测漂移、损坏链接、过期 Skill。
- 冲突解决：可视化显示 override 差异，提供“一键接受全局版本”或“保留项目版本”选项。

### 5. 用户交互流程（文本描述）

1. 启动工具 → 自动扫描工具和已注册项目。
2. 主界面左侧：工具选择（Claude / Cursor...） + 项目列表。
3. 选择 Claude → “所有项目” 或 具体项目名。
4. 右侧表格显示 Skill 列表 + 操作按钮（同步、编辑、删除、查看详情）。
5. 点击“从中央仓库同步” → 弹出可选项目列表 → 确认执行。
6. CLI 模式同样支持对应命令（如 `sync --project my-app`、`delete --project my-app --skill xxx`）。

### 6. 非功能性要求

- **性能**：扫描 50 个项目 < 5 秒，同步操作秒级完成。
- **安全性**：仅操作本地文件，不上传 Skill 内容（可选加密云同步）。
- **兼容性**：优先支持 Claude Code 项目 Skill 路径，也可扩展 Cursor 等。
- **跨平台**：macOS / Windows / Linux 一致体验。
- **可扩展性**：通过适配器模式轻松增加新工具支持。
- **Git 友好**：中央仓库和项目目录均可直接 commit。

### 7. 开发路线图（建议分阶段）

**阶段 1（MVP，2-3 周）**：中央仓库 + 全局 CRUD + 单工具（Claude）同步
**阶段 2（核心，2 周）**：项目注册表 + 项目级视图 + 项目 CRUD + 同步
**阶段 3（完善，1-2 周）**：版本管理 + 健康检查 + 多工具适配 + CLI 完整版
**阶段 4（高级）**：批量操作、云同步、团队权限

### 8. 设计优势

- 真正实现“Install once, sync everywhere”，中央仓库为唯一真相。
- 项目级管理直观可视，完美支持官方分级优先级。
- 极大降低手动维护成本，同时保留灵活的 override 能力。
- 易于后续扩展成团队共享仓库或技能市场。
